## 07:45 ~ 10:59
## ego: [节点软件]

- 现状和未来
	- 传统软件和AI agent、端侧大模型融合成为统一的新节点软件。
	- 节点安装会非常简易，很可能预安装，或者开箱即用、无专业操作。
	- 节点拥有统一的主用户界面，节点不断修改自己的主界面，适应用户习惯。
	- 端侧模型可以应付自然语言分析和日常简单问题，硬件条件好的可以处理更大任务。外部模型处理高强度问题。
	- 节点调用本地agent或向外委托，不断开发、修改传统软件的代码，或者寻找现成的软件（插件）、代码块。
	- 节点是可重配置的，每部分都作为插件管理。
	- 节点有通信功能，包括对人的自然语言接口和对其它节点的接口（含元协议：从自然语言到结构化数据）。
- 大厂生态位：
	- agent、agentOS
	- model provider、router
	- protocol
- IT人员生态位
	- skill、MCP server
	- plugin
	- 节点软件
		- 通信层
- 其它专业人员生态位
	- 人工提供服务
	- 借助节点提供自动服务，人工锋面得以拓展
- ego：
	- 早期：打通agent和传统软件的融合。
	- 大厂节点软件成熟：专业节点网络：插件方式将节点构造成信任链、PSMD等专业网络
	- 远景：资源引向底层锋面。
- 演进路径
	- 大厂会完成节点的基础功能。
	- IT人员会制造大量重复的工具，但缺乏知识跨度和认知能力去做应用层和深层元协议。
	- 专业人员会在本地积累知识。
	- 从散装阶段自己构建节点，保持跟进大厂版本，针对性地吸收和兼容。
	- 定量分析各专业赛道各角色所缺少的算力和购买力，规划专业节点网络的边界。
