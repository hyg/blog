## 19:00 ~ 19:59
## check: [零散笔记]

- 按照需求端的意见，我们把agent划分为层级：某一层调用llm的prompt由下一层生成。
    - 纯人工手写：人[n] -> prompt -> llm[n+1]
    - 传统代码生成、不消耗token: code[n] -> prompt -> llm[n+1]
    - 这两种情况之间有一些是调llm的：prompt-1 -> llm[n] -> prompt-2 -> llm[n+1]

- 所有层级集成的代码目前看是传统代码按简单状态机运行就可以，不需要消耗token。
- 每个层次独立的演进过程，其实是：人工手写 -> 调用llm -> 传统代码
    - 终点是传统代码，相邻层都演进到终点后可以合并。
- 人工手写这层，是可以远程委托、受托的，利用别人的经验启动这一层的演进。
